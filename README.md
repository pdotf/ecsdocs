# ECSDocs

ECSDocs is a project aimed at simplifying and organizing documentation for ECS (Entity Component System) based applications. This repository contains resources, frameworks, and tools to achieve better documentation management and enhance the workflow for projects using ECS design patterns.

## Features
- Comprehensive documentation framework tailored for ECS-based projects.
- Predefined templates for common ECS documentation scenarios.
- Lightweight and easy to integrate with existing systems.

## Getting Started

### Requirements
- **C#/.NET Framework**: Ensure you have the necessary runtime to support this project.
- **Web Browser**: Recommended browser for accessing documentation generated.

### Installation
1. Clone this repository:
   ```bash
   git clone https://github.com/pdotf/ecsdocs.git
   ```
2. Navigate into the project folder:
   ```bash
   cd ecsdocs
   ```

3. Build the project:
   Follow your usual build process for C# applications.
